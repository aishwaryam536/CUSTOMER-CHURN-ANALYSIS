# Customer Churn & Revenue Analysis – Power BI

## Project Overview

This project analyzes customer churn, revenue, and customer charges using Microsoft Power BI.

The project transforms customer data into interactive dashboards to understand customer churn patterns, revenue distribution, monthly charges, contract types, internet services, payment methods, customer demographics, and geographic trends.
