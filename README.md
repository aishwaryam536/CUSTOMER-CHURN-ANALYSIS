# Customer Churn Analysis – Python, SQL & Power BI

## Project Overview

This project analyzes **customer churn and retention** to identify customer behavior, churn patterns, trends, and factors related to customer retention.

## Objectives

- Analyze customer churn patterns and trends.
- Identify customer segments with higher churn.
- Understand factors related to customer retention.
- Use data analysis and visualization to generate meaningful insights.

## Tools & Technologies

- **Python**
- **Pandas**
- **NumPy**
- **Jupyter Notebook**
- **MySQL**
- **SQL**
- **Power BI**
- **DAX**

## Project Workflow

### 1. Data Cleaning & Preprocessing

Performed data cleaning and preprocessing using **Python, Pandas, and NumPy** to prepare the dataset for analysis.

The data was checked for:
- Missing values
- Duplicate records
- Data type inconsistencies
- Inconsistent data
- Outliers

### 2. Exploratory Data Analysis

Performed exploratory analysis using Python to understand customer behavior and identify **churn patterns, trends, and relationships** within the dataset.

### 3. SQL Analysis

Used **MySQL and SQL queries** to analyze customer churn across different customer segments and identify patterns related to churn and retention.

### 4. Power BI Dashboard

Developed an interactive **Power BI dashboard** to visualize customer churn, key metrics, trends, and customer segments using interactive charts, KPIs, and filters.

## Key Analysis Areas

- Customer churn
- Customer retention
- Churn patterns and trends
- Customer segments
- Contract types
- Internet services
- Payment methods
- Customer tenure
- Subscription-related factors
